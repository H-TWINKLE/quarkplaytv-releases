# QuarkPlay TV

Android TV 上的夸克网盘播放器：扫码登录 → 搜索资源 → 一键转存 → 4K 原画播放。
凭证只保存在你自己的电视上，不经过任何第三方。

**最新版下载：** [Releases](../../releases/latest)（仅 arm 包，约 13 MB，Android 7.0+）

---

## 安装

1. 下载 `QuarkPlayTV-vX.Y.Z-arm.apk`，拷到 U 盘插电视
2. 电视上用「应用安装 / 文件管理」打开它，允许「未知来源」安装

或用 adb：

```bash
adb connect <电视IP>:5555
adb install -r QuarkPlayTV-vX.Y.Z-arm.apk
```

> 覆盖升级会保留登录态与播放历史，不用卸载旧版。

---

## 使用

1. **登录**：打开 App → 设置 → 网页通道 → 手机夸克 App 扫码
2. **找片**：首页搜索或点热词，选一个资源进详情
3. **转存**：详情页右上角「一键转存全部」（建议先存，之后每集秒开）
4. **播放**：点任意一集即可，起播约 2–3 秒

设置项支持手机扫码输入，不用在电视上打字。

---

## 功能

- 搜索：聚合全网夸克分享链接
- 转存：整部剧一键搬进自己网盘，幂等可重复点
- 播放：4K HEVC 硬解，会自动绕过限速，控制器显示网速与分辨率
- 遥控器：左右键快进快退、长按上键加速、菜单键唤出控制栏、选集 / 倍速 / 续播 / 片头片尾
- 自动更新：有新版本会提示，确认后覆盖安装
